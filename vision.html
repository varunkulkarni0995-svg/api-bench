Vision eval v1.1.0

Same photo, same schema, every model. Scored against your own labels.

0What this is

Compare models asks each model a question and shows you the prose. This page does the harder thing: it forces every model to answer in one fixed JSON shape, then scores the answers against labels you set yourself. Use it to pick a model and settle a prompt before wiring either into a product.

2Task and schema

Enforcement is the experiment. "Auto" uses each provider's strongest mechanism — a response schema on Gemini, a forced tool call on Anthropic, json_schema on OpenAI-compatible routes that take it. Set it to Prompt only to see which models hold the shape with nothing but instructions; that difference is usually the most useful thing on this page.

3Fixtures

Shoot a garment, then press Run eval. The photo is resized in the browser and the metadata, GPS included, is dropped before anything is sent.

Label each photo yourself — that label is the truth everything is scored against. Mark photos with no garment at all as negatives: a model that confidently reads a garment out of a blanket or a desk has failed, and that is the single most important thing to measure.
